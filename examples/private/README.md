# Example Private Directory

This directory shows the shape of a NuSelf private memory folder that is safe to commit.

Real personal memory should live in the repository root at `private/`. That root directory is ignored by Git and should contain private source material, local profile state, and share bundles that are not meant to be published with the codebase.

Use this example directory for tests, documentation, demos, and as the template for creating a local `private/` directory.
